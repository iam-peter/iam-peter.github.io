Portfolio website for the sculptor and installation artist Kimberly Meenan.

The first version from 2010 was built with HTML, jQuery, PHP and CSS, with a
custom content management system to maintain the projects. In 2020 I rebuilt
it as a responsive static Hugo site with a filterable project overview, and
have kept extending it since, most recently with a light and dark mode.
